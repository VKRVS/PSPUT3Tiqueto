# 🎫 PSPUT3Tiqueto

**PSPUT3Tiqueto** es una aplicación de escritorio desarrollada en **Java** con **JavaFX**, centrada en la gestión de tickets o incidencias. Ha sido diseñada como parte de la formación en el *CFGS Desarrollo Aplicaciones Multiplataforma*.

## 🧩 Funcionalidades Principales

- Gestión de incidencias con creación, consulta y resolución de tickets.
- Interfaz gráfica intuitiva usando **JavaFX**.
- Almacenamiento persistente de los datos mediante ficheros planos.
- Validación de entrada de datos y control de errores.
- Organización modular del código siguiendo buenas prácticas de POO.

## 💻 Tecnologías Usadas

- **Lenguaje:** Java
- **Interfaz gráfica:** JavaFX
- **IDE recomendado:** IntelliJ IDEA o Eclipse
- **Persistencia:** Archivos de texto

## 📂 Estructura del Proyecto

```
PSPUT3Tiqueto/
├── src/
│ ├── application/ # Controladores e inicialización
│ ├── controller/ # Controladores JavaFX

│ └── utils/ # Utilidades auxiliares

│ └── styles/ # CSS para el estilo visual

 ```
